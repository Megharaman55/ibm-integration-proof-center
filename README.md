# IBM Integration Proof Center

An interactive, high-fidelity concept prototype exploring outcome-oriented technical proof journeys for IBM Integration prospects and customers.

---

## Overview

The **IBM Integration Proof Center** explores an alternative to the traditional open-ended "Start free trial" conversion model by allowing enterprise integration prospects to choose a specific technical outcome they need to prove before committing to a larger evaluation or implementation:

1. **Offer 1: AI-Assisted Development** — *Can AI handle your toughest integration?*
   - Evaluate FlowServices, EDI mappings (ANSI X12 850), SAP-to-Salesforce synchronization, or legacy ESB modernization using **IBM webMethods Flow Pilot** and **Integration Intelligence Hub**.
   - Review an illustrative, evidence-based scorecard (functional correctness, unit test coverage, manual rework, and maintainability).

2. **Offer 2: Consolidation & Modernization Assessment** — *What could you reuse before you rebuild?*
   - Assess enterprise integration estates across APIs, B2B/EDI, Managed File Transfer (MFT), and event streaming.
   - Explore dependency matrices, potential reuse opportunities, resilience/DR factors, and a phased 3-wave migration roadmap.

3. **Offer 3: Governed AI Integration Proof** — *Can your AI agent work safely with enterprise systems?*
   - Simulate an autonomous AI agent investigating an ERP purchase order variance across enterprise backends.
   - Test runtime access controls, dynamic PII masking, human-in-the-loop financial approval thresholds, and SIEM audit logging powered by **IBM DataPower Interact Gateway**.

4. **Internal Leadership & PMM View**
   - Strategic rationale, A/B experiment design, interactive conversion funnel simulator, and measurement scorecard.

## Live Demo & Usage

### Running Locally
1. Clone or download this repository.
2. Open `index.html` in any modern web browser (Chrome, Safari, Edge, Firefox).

### Viewing on GitHub Pages
To host this prototype publicly via GitHub Pages:
1. Go to your repository **Settings** &rarr; **Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose the `main` branch and `/ (root)` folder, then click **Save**.
4. The live prototype will be accessible at: `https://<your-username>.github.io/<repo-name>/`
